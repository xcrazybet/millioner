⚡ Real-time Subscriptions

Live updates for dynamic content.

Live Scores Subscription
Single Match Subscription
// Subscribe to live matches const subscription = FootballDataHub.subscribeToLiveMatches( data => { console.log('Live matches updated:', data.data.length); updateLiveScores(data.data); }, { interval: 10000, // Update every 10 seconds filters: { league: 'Premier League' } // Filter by league } ); // Subscribe to specific match const matchSub = FootballDataHub.subscribeToMatch( 'match_id_here', data => { console.log('Match updated:', data.match.score); updateMatchDetails(data); }, { interval: 5000 } // Update every 5 seconds ); // To stop subscription subscription.unsubscribe(); matchSub.unsubscribe();
